# Body-of-Revolution (BoR) Solver — Scoping Document

Delivered scope: true 3-D monostatic RCS (dBsm) of axisymmetric targets
(rockets, missiles, cone-spheres, coated cylinders) at **all aspect angles
including nose-on**, reusing the existing 2D solver's geometry, material,
and GUI infrastructure.

---

## 1. Formulation

**Method: BoR-MoM via azimuthal Fourier decomposition** (Andreasen;
Mautz–Harrington). The surface is generated by rotating a curve
(*generatrix*) in the (ρ, z) half-plane about the z-axis. Because the 3-D
Green's function depends on azimuth only through φ−φ′, expanding surface
currents as

    J(t, φ) = Σ_m [ J_t^m(t) û_t + J_φ^m(t) û_φ ] e^{jmφ}

decouples the problem into **independent 1-D integral equations along the
generatrix, one per mode m** — each a small dense system, embarrassingly
parallel across modes. This is *not* the 2D scalar problem: currents are
vectors (t and φ components couple within a mode), and the kernel is the
**modal Green's function**

    G_m(t, t′) = ∫_{−π}^{π}  e^{−jkR} / (4πR) · e^{−jmξ} dξ ,
    R(ξ) = sqrt(ρ² + ρ′² − 2ρρ′ cos ξ + (z−z′)²)

plus cos ξ / sin ξ weighted variants for the dyadic terms. Everything stays
in the project's e^{+jωt} convention.

**Boundary conditions, per mode:**

| Existing TYPE | BoR treatment |
|---|---|
| 2 (PEC) | EFIE (phase 1); CFIE for closed bodies (phase 2, interior resonances) |
| 2 + IBC (incl. tapered) | Leontovich term on IBC-EFIE rows; nonzero IBC with CFIE/MFIE is rejected |
| 3/5 (dielectric) | PMCHWT per mode for the explicitly supported homogeneous/layered layouts (J and M densities; 2× unknowns per interface) |
| 4 (coated PEC) | PMCHWT region coupling + PEC core (multi-region, phase 3) |
| 1 (sheet) | not implemented in the BoR dispatcher; rejected |

PMCHWT chosen over Müller: better documented for BoR, handles junctions;
revisit only if high-contrast conditioning bites.

**Excitation & far field:** plane wave at aspect angle θ from the axis,
θ̂/φ̂ polarized (true VV/HH), modal coefficients via Jacobi–Anger
(J_m(kρ sin θ) factors). Far field per mode by the modal radiation
integral; σ = 4π r² |E_s|²/|E_i|² in m² → dBsm directly. Cross-pol is
zero for the supported monostatic axisymmetric solve, and VV/HH decouple by
BoR symmetry. Arbitrary bistatic observation directions and bistatic
cross-polarized outputs are not implemented by the public solver.

**Mode count:** driven by *radius*, not length: m_max ≈ k·a_max·sin θ + margin.
Nose-on needs only |m| = 1. Adaptive truncation: add modes until the
far-field increment < tol (natural quality gate, mirrors the existing
quality-gate philosophy).

**Known hard points (all standard, all planned):**
- *Axis conditions at ρ = 0*: for |m| ≠ 1 both current components must
  vanish at axis endpoints; |m| = 1 needs the J_t ± jJ_φ finite
  combinations. Handled by mode-dependent end-basis selection
  (Mautz–Harrington). This is the classic BoR gotcha — gets its own tests.
- *Singular self terms*: after the ξ-integration the t-kernel has a
  ln|t−t′| singularity — exactly the structure the 2D solver's
  `_single_layer_self_block_exact` log-moment machinery handles; the same
  extract-the-log-analytically pattern applies.
- *Interior resonances*: closed PEC bodies need CFIE (phase 2); until then
  the residual/condition monitoring flags affected frequencies.

## 3. Phases and validation gates

Each phase lands only when its gate passes — same discipline as the 2D
review (analytic reference or cross-solver check, never "looks right").

**Phase 0 — references & conventions. ✅ DONE (July 2026).**
`mie_sphere.py` + `BOR_CONVENTIONS.md`. Modal coefficients solved from
boundary conditions per mode (not transcribed from tables); 18/18 anchor
gates pass: Rayleigh dipole limits incl. the ε,μ-combined case (~1e-5),
GO limit (1e-5 at ka=300), resonance peak 3.655, optical theorem
(machine precision), **Weston's theorem** (Z_s=η0 sphere backscatter
exactly zero — this anchor caught a TE Leontovich sign error on the first
write, the precise analog of the 2D solver's TE bug; it is the phase-2
IBC gate), coated degenerate limits (1e-13), bistatic↔monostatic
consistency. Validation battery: scratchpad `validate_mie_sphere.py`.

**Phase 1 — PEC EFIE core. ✅ DONE (July 2026).**
`bor_kernels.py` (generatrix, modal Green's functions: FFT far path
spectrally accurate, two-piece sinh-core + oscillation-scaled-tail near
path self-converged to 1e-12; unit-tested against adaptive integration)
+ `bor_solver.py` (mixed-potential EFIE — only G needed, no kernel
gradients; triangle bases both components; quadtree-graded near-pair
Galerkin; mode-dependent axis conditions; Jacobi–Anger excitation; modal
far field; adaptive mode truncation; `solve_bor_pec`). Gates
(scratchpad `validate_bor_phase1.py`): PEC sphere ka=0.5–6 at 4 aspects
× both pols ≤0.085 dB worst; **broadside cylinder vs the 2D solver ×
2L²/λ: −0.036 dB (VV/TM), −0.005 dB (HH/TE)** — ties the two solvers
together; cone-sphere nose-on VV≡HH to 1e-4 dB (exact BoR symmetry),
mesh-converged to 0.01 dB, classic VV-only traveling-wave null present,
rear-on within 2.2 dB of the isolated Mie sphere.
Lesson recorded: the near modal kernel needs the singular core CAPPED
(s0 ≤ 0.25) so the oscillation-scaled Gauss tail always covers the rest —
a full-range sinh map silently loses 2–3 digits.

**Phase 2 — CFIE + IBC. ✅ DONE (July 2026).**
MFIE via assembled-bracket modal kernels (the 1/R³ pieces are only weakly
singular AS A WHOLE, so the bracket is built inside the azimuthal
integrand — separate kernel tables would cancel catastrophically);
CFIE = α·EFIE + (1−α)·η0·MFIE; IBC-EFIE with the magnetic current
M = −Z_s n̂×J eliminated (½Z_s mass + source-normal ∇G×M operator) AND
radiating in the far field.  Gates (scratchpad `validate_bor_phase2.py`,
9/9): CFIE/MFIE sphere ≤0.03 dB; EFIE conditioning spikes at the cavity
ka while CFIE stays flat (132 vs 9800); IBC sphere ≤0.023 dB over four
impedances; **Weston null −59 dB rel PEC**; Zs→0 = PEC; tapered-IBC
mirror symmetry to 1e-14 dB.  Phase-1 battery re-passes.
Lessons recorded: (a) graded self-cells must use DIFFERENT Gauss orders
on test/source axes or coincident nodes underflow the 1/R³ kernel to NaN;
(b) the eliminated IBC magnetic current still RADIATES — omitting its
far-field term leaves the operator right but the RCS wrong, and Weston's
theorem is precisely the gate that catches it (it failed at −5.6 dB,
passes at −59 dB with the term).

**Phase 3 — dielectric & coated (PMCHWT, multi-region). ✅ DONE (July 2026).**
`solve_bor_dielectric` (per-mode PMCHWT, 4Nn unknowns J/M′=M/η0) and
`solve_bor_coated_pec` (3-block multi-region: J_o, M′_o on the interface,
J_c on the PEC core, cross-surface T/P operators via `BorCrossOperators`
with distance-based near-pair refinement).  Gates (tests/
`validate_bor_phase3.py`, 11/11): dielectric sphere lossless/lossy/
magnetic/ε=9 ≤0.046 dB; **ε=1 body null −92 dB rel PEC** (the sharpest
sign anchor); coated PEC lossy/thin(b=0.9a)/magnetic-RAM/lossless ≤0.065 dB;
ε=1 coating ≡ bare PEC core 0.009 dB; mirror symmetry 1e-14.  Phase-1/2
batteries re-pass after the refactor.
Lessons recorded: (a) the phase-2 IBC bracket machinery IS the PMCHWT
magnetic-current operator — M = −Z_s n̂×J had the n̂× rotation built into
the brackets, so the independent-M operator is a pure column remap
(P[:,M_t] = −B[:,f_φ], P[:,M_φ] = +B[:,f_t]), no new quadrature; the SAME
bilinear form gives the H-row J operator (<W,H_PV(J)> = −P J).
(b) Medium impedance must be η = η0·μ_r/m (m the causal index), not a
free-standing sqrt(μ/ε) — it keeps kη = ωμ0μ_r exactly for whichever
branch the causal index took.  (c) The unrotated <W, H_inc> is the
polarization-swapped rhs_mode (×∓1/η0) — no new excitation integrals.
(d) Deriving PMCHWT as [exterior-representation interior limit] MINUS
[interior-representation exterior limit] cancels every ½-jump identity
term; adding them instead yields a Müller-like mix with sign traps.

**Phase 4 — integration & scale. ✅ DONE (July 2026)** (native kernel and

**Phase 5 — partial-coating junctions. ✅ DONE (July 2026).**
`solve_bor_partial_coating`: coatings that TERMINATE on the PEC surface
(RAM caps and bands) — the classic triple line where air, dielectric, and
conductor meet.  Structure: exterior region bounded by the interface S_d +
bare PEC pieces, layer region by S_d + covered core; PMCHWT rows on S_d,
EFIE rows on the PEC pieces, all from the existing T/P operator blocks;
`BorCrossOperators` now allows surfaces to touch at shared junction
endpoints (junction-adjacent element pairs route to the same graded
corner-cell quadrature the same-surface assembly uses — all four
cornerXY kinds verified).  Junction conditions per circle: through-current
ties J_bare(A) = (+t, +φ)·J_d(A) and J_cov(A) = (+t, −φ)·J_d(A) (KCL /
chain continuity; the φ flip is the layer chain traversing S_d reversed),
M_t(A) = 0 (E_φ shorts on the conductor), M_φ(A) free with its natural
half-triangle end basis; reduction A_red = QᵀAQ, with the `_mode_sweep`
engine generalized to closure-owned reductions (mask=None).  Dispatch
routes TYPE 2+3+4 mixed .geo geometries here (bare pieces PEC-only for
now; the merged covered+bare core must still preflight as a closed body).
Gates (tests/`validate_bor_junctions.py`, 9/9): full coverage ≡ phase-3
coated solver (bit-identical); **ε=1 cap and band ≡ bare PEC Mie**
(0.097/0.15 dB, mesh-converging — this gate caught the one real bug, see
below); shrinking bare cap → fully-coated Mie (0.17→0.005 dB); mirror
symmetry with a lossy magnetic cap 1e-14; RAM cap mesh convergence;
dispatch TYPE 2+3+4 ≤ 0.021 dB.  Phase-1..4 batteries re-pass.
Lesson recorded: with junction row-folding, EVERY per-surface row block
must carry the SAME region-equation orientation — rows are −(AirEq) on
air-bounded surfaces, −(AirEq − LayEq) on the interface, and therefore
**−LayEq (not +LayEq as in the junction-free coated solver) on the covered
core** — because Qᵀ SUMS the piece rows at a junction, and a flipped block
adds the layer equation with the wrong sign there (the through-DOF row
becomes inconsistent; ε=1 cap failed at +9.4 dB, non-convergent, error
peaking AT the junction node).  Equivalently: test weights must equal the
region-current weights (the same ±1s that map unknowns into each region's
equivalent currents) — the prescription that makes PMCHWT itself emerge
as Ext − Lay.  Remaining junction scope: coatings terminating on other
coatings (multi-layer junctions).

**Phase 5b — IBC on the bare pieces. ✅ DONE (July 2026).**
`bare_zs` on `solve_bor_partial_coating` (None / scalar / per-element
tapers per piece); dispatch accepts TYPE 2 segments with IBC flags (incl.
inline tapers and mat.N tables) next to TYPE 3+4 coatings.  Treatment:
the piece's own operator stays on the validated Gauss-point IBC-EFIE path
(`assemble_ibc_extra`); the eliminated magnetic current
M₁ = −Z_s n̂×J₁ radiates onto the OTHER surfaces through the existing
cross T/P operators via the nodal column map (M₁t, M₁φ) =
(+Z_s J₁φ, −Z_s J₁t) — no new singular quadrature; M₁ also radiates in
the far field (existing zs path).  Junction condition: **M_t(A) = 0 is
kept even at impedance junctions.**  Two alternatives were tried against
the exact cross-check and rejected: a pointwise tie
M_t(A) = Z_s(A)·J_φ(A) fails at +7.6 dB (with an abrupt Z_s the junction
line co-locates the impedance step with the material wedge — E_φ along
the line is genuinely discontinuous in the sheet model, so no pointwise
nodal value is consistent), and a free half-basis M_t end DOF fails at
5.5 dB non-convergent (nothing controls the lone end DOF).
Convergence finding: with Z_s TAPERED to zero at the junction (the
physical RAM edge treatment) the solution mesh-converges cleanly
(0.12→0.10 dB vs a 6× fine single-surface truth); with an ABRUPT Z_s at
the junction it does not (≈0.5 dB plateau) — that configuration is an
ill-defined sheet-model limit, and the solver now emits a warning when
|Z_s| > 0.02·η0 at a junction.  Gates (validate_bor_junctions.py now
17/17): ε=1 cap + tapered-IBC bare ≡ the single-surface mixed
PEC/impedance sphere (validated phase-2 path) 0.083 dB; abrupt-Z_s loose
gate 0.39 dB + warning; Z_s=0 ≡ PEC path bit-identical; mirror symmetry
with tapered IBC + lossy cap 1e-14; dispatch TYPE 2(IBC)+3+4 0.083 dB.
Phase-1..4 batteries re-pass.

**Phase 6 — multi-layer coatings & dielectric junctions. ✅ DONE (July 2026).**
The phase-5 lesson mechanized into a generic multi-region assembler
(`_MultiRegionBor`): every block is
A[u_s, u_s'] += σ_rs σ_rs' × (T_r or ±η0 P_r or (η0/η_r)² T_r) summed over
regions r, and junction ties follow the σ/traversal rule
(t: σ_m dir_m J_m,t = −σ_s dir_s J_s,t — cycle-consistent; φ: σ_m J_m,φ =
σ_s J_s,φ via a region shared with the master — the 3-region φ cycle is
inconsistent because H·t̂ differs per surface, so the third pairwise
relation is left to the Galerkin system; M ties identical to J at
pure-dielectric junctions, no conductor masks).  The construction
reproduces the phase-3 coated system to machine precision INCLUDING the
phase-5 row-orientation fix automatically.  New entry points:
`solve_bor_coated2_pec` (two full layers) and `solve_bor_coating_patch`
(a second-layer patch terminating on the inner coating's interface —
air/patch/inner-layer dielectric TRIPLE junctions, no metal on the line).
New reference: `mie_sphere.sigma_multilayer_pec_sphere` (PEC core + N
layers, per-mode radial matching solved as a small linear system;
degenerate anchors at 1e-15).  Dispatch: TYPE 3+5+4 layouts (TYPE 5 =
layer|layer interface; pos_mat/neg_mat = outer/inner flags; TYPE 3 chains
with the inner-layer flag are the exposed inner interface of a patch
layout).  Gates (tests/`validate_bor_multilayer.py`, 12/12): 2-layer
spheres vs multilayer Mie ≤0.058 dB (lossy/magnetic/lossless);
ε_patch=1 ≡ single-layer Mie (0.14→0.025 dB converging);
**ε_patch=ε_inner ≡ bumped-profile single-region solve** (same continuum
problem, different region decomposition: 0.44→0.13→0.09 dB converging);
full-coverage patch ≡ two-layer bit-identical; mirror 2.5e-14; RAM patch
convergence; both dispatch layouts.  All prior batteries re-pass.

**Phase 7a — scale pass part 1: precision + budgeting. ✅ DONE (July 2026).**
Far kernel tables (the persistent memory bound) can be stored complex64:
`table_precision="auto"|"single"|"double"` on `solve_bor` and the dispatch
(auto switches to single above 4 GB of double tables and notes it in the
result warnings).  Validated: single vs double differs by 1.6e-8 dB on the
CFIE/IBC sphere gates — the smooth far tables are insensitive; near/self
quadrature and the assembled mode systems stay double.
`estimate_bor_table_gb` + a hard 32 GB gate with actionable messages.
Result dicts record `table_precision`.

Current capacity (all-modes-at-once table assembly, CFIE closed PEC):

N_t=250/m≈25: 2.6 GB single; N_t=500/m≈40: 12 GB single (fits);

25 ft @ 3 GHz (N_t≈3200, m≈30): 360 GB single — the streaming rework is

**Phase 7b — streaming assembly. ✅ DONE (July 2026).**
`bor_streaming.StreamingFarBlocks`: element-tiled azimuthal sampling
([rows, P, n_xi], tile size from a memory budget) → FFT (all modes at
once, keeping the amortization) → immediate two-sided Galerkin contraction
through the reference shape functions into per-mode NODAL blocks.
EFIE stores 9 order-primitives (the Gc/Gs neighbor relations and the
mode-dependent scalars commute with contraction — per-mode blocks combine
on retrieval, with ztt/zff even and ztf/zft odd in m); MFIE/IBC store
their 4 bracket blocks over the full signed mode range (IBC with the
solve's Z_s baked into the source contraction).  All modes contract in
ONE einsum per weight-pair per tile — a per-mode Python loop was 10x
slower at scale.  The near/self machinery is untouched; solver hooks swap
only the far parts.  `assembly="auto"|"tables"|"streaming"` on solve_bor
and the dispatch; auto switches at 2 GB of double tables — deliberately
early, because the TABLE builders sample [P, P, n_xi] in one shot and
their construction PEAK is several times the stored size (a 7.99 GB table
estimate thrashed a solve into a 10-minute timeout while the streamed run
took 65 s — the bug that set this threshold).
Gates (tests/`validate_bor_streaming.py`, 8/8): bit-level equivalence
with the table path (2-4e-15 on EFIE/CFIE/IBC — same xi grid, same FFT,
same Galerkin points); CFIE ka=10 / N_t=400 sphere 0.0020 dB vs Mie in
65 s; auto-selection both directions; estimate ratio ~12x.
**Capability demo: CFIE sphere ka=20, N_t=800 — 48 GB of tables
(infeasible) vs 2 GB of streamed single-precision blocks: 0.0019 dB vs
Mie in 7.1 min, residual 8.5e-15.**  All prior batteries re-pass
(small cases stay on the validated table path under auto).

**Phase 7d — mode-block re-sweeps. ✅ DONE (July 2026).**
`StreamingFarBlocks` is now range-based: it holds per-mode blocks only
for an ALIGNED range of modes (range size a multiple of the mode-sweep
engine's worker count, so a thread wave never straddles a rebuild) and
re-runs the (native, threaded) sampling sweep when the mode loop
advances past it — held memory / n_ranges at sampling cost x n_ranges.
Retrieval is serialized under the range lock; the xi grids stay sized
for the FULL mode set so every range remains bit-identical to the table
path.  `stream_budget_gb` (default 8) on solve_bor picks the block size
automatically; the 32 GB gate now applies to the HELD size.  Result
dicts record `stream_mode_block` / `stream_sweeps`.
Gates (validate_bor_streaming.py now 12/12): mode-blocked (3 sweeps)
== tables to 1.3e-15, including under threaded waves.  Big-case check:
the ka=20 / N_t=800 CFIE showcase under a 1 GB budget runs 2 sweeps at
the same 0.0019 dB in 3.0 min (vs 2.3 unblocked) — ~30% time for half
the memory.  Projection for 25 ft @ 3 GHz (N_t~3200, m~30, CFIE): ~22 GB
single-precision blocks unblocked -> ~8 GB held with the default budget
at ~3 sweeps; assembly is no longer the constraint there.  The extreme
25 ft @ 20 GHz corner remains out of reach for a different reason: the
per-mode SOLVE matrices themselves (~25 GB each at N_t~21000) — as the
cost model always said.

**Phase 9 — banded (side-by-side) coatings. ✅ DONE (July 2026).**
Motivating case: a PEC body with alternating MAGRAM bands (TYPE 5 walls
where band touches band) — previously a hard `ValueError` in dispatch.
No new solver: each band is one region of the generic `_MultiRegionBor`
assembler (air = all out+bare pieces at σ=+1; per band, a connected
component of its out/wall pieces with σ from which side the wall's
pos_mat faces).  Dispatch classifies TYPE {2,3,4,5} (or {3,4,5} with
several TYPE-4 materials) as `banded`, stitches covered/out/wall runs
per flag, and labels the result "PMCHWT banded coatings (N band(s),
J junction(s))".  Banded bare pieces are PEC-only for now (IBC bare
remains a phase-5-path feature).  Authoring rules live in
GEOMETRY_GUIDE.md (adjacent bands need different flags; wall pos_mat =
band the left normal faces; TYPE 3 edge walls at bare junctions).
Gates (validate_bor_banded.py, 6): two ε=1 bands + fictitious wall ≡
PEC Mie converging 0.15 → 0.044 dB; same-magram fictitious wall ≡
coated Mie 0.026 dB; band-swap mirror symmetry converging 2.2e-2 →
2.5e-3 dB; dispatch end-to-end ε=1 ≤ 0.069 dB at N=−60; two-magram
banded cone demo (4 bands, 7 junctions) residual 4e-15
(demo_banded_cone.geo).  Investigation note: a +0.17 dB pole anomaly in
the lossless ε=1 wall gate at one mesh/frequency proved to be a detuned
discrete resonance of the fictitious lossless band cavity (±1 %
frequency jitter kills it; real lossy MAGRAMs damp it) — documented as
the "jitter check" in the guide.  Fallout fix with global reach:
`n_xi_for_pairs` (bor_kernels) now floors the azimuthal FFT grid by the
minimum far-pair meridian gap — the old k/m-only sizing under-resolved
just-outside-near pairs on fine meshes, a NON-convergent error floor
affecting every assembly path; wired identically into same-surface
tables, cross-operators, and streaming (bit-equivalence preserved), and
the FFT table builders now chunk their [pairs, n_xi] sampling grids
under `FFT_BUILD_BUDGET` (the enlarged grids otherwise OOM-killed whole
validation batteries; chunking is exact).

**Phase 7 design notes (historical).**
Replace stored Gauss-point tables with per-mode NODAL Galerkin blocks
accumulated from row-block sweeps: for each block of test Gauss points,
sample the azimuthal integrand [rows, P, n_xi], FFT (all modes at once,
keeping the amortization), then contract BOTH Galerkin sides immediately
and accumulate into per-mode nodal blocks — 4·N_t²·(2m+1) storage instead
of 4·(4N_t)²·(2m+1), a 16x reduction (plus 2x single = 32x):
N_t=3200/m=30 CFIE ≈ 20 GB single → the 25 ft @ 3 GHz point becomes
feasible; combine with mode-block re-sweeps (compute × n_blocks, memory ÷
n_blocks) for the 10-20 GHz corner, and move the [rows, P, n_xi] sampling
loop to a ctypes kernel (pattern proven with fmm_near.c).  The EFIE needs
9 contracted primitives per order (T/D-weighted combos of G with the
tangent products; Gc/Gs neighbor relations commute with contraction);
MFIE/IBC need their 4 brackets each.  Aspect sweeps keep the
factor-once-per-mode structure unchanged.

## 4. Cost model and scale engineering

**Confirmed requirements (July 2026):** bodies from 1 ft (0.3 m) to 25 ft
(7.6 m); frequencies from sub-1 GHz to ~20 GHz; PEC + IBC (incl. tapers)
land first, dielectrics/coatings in phase 3.

Unknowns per mode: u·N_t (N_t = generatrix elements ≈ 15–20/λ of curve
length; u = 2 for PEC/IBC, 4 for PMCHWT). Modes M ≈ k·a_max·sin θ + margin.
Modes parallelize across cores.

**Assembly strategy (required by the 20 GHz end): FFT over azimuth.**
Sample the kernel e^{−jkR(ξ)}/R(ξ) on a uniform ξ grid and FFT — one FFT
per (t, t′) pair yields the modal kernels for **all m simultaneously**.
Total assembly cost O(N_t²·Q_ξ log Q_ξ) for the whole mode set, instead of
O(M·N_t²·Q_ξ) mode-by-mode. This is the classic BoR optimization and it is
what makes the upper band tractable. The sampled-azimuth inner loop is the
natural native-code candidate (ctypes pattern proven with `fmm_near.c`).

| Scenario | gen. length | N_t | modes | feasibility |
|---|---|---|---|---|
| 1 ft @ 1 GHz | ~2λ | ~40 | ~6 | instant |
| 25 ft @ 3 GHz (a ≈ 0.4 m) | ~160λ | ~3200 | ~30 | minutes, pure NumPy + FFT assembly |
| 25 ft @ 10 GHz | ~535λ | ~10500 | ~90 | ~1 h; native azimuth kernel + parallel mode LUs; one mode matrix ≈ 6.4 GB — solve modes streaming, never hold all |
| 25 ft @ 20 GHz | ~1070λ | ~21000 | ~175 | hard corner: one PEC mode matrix ≈ 25 GB double / 12.6 GB single. Plan: single-precision mode solves (validated against double at 10 GHz), streaming one mode at a time; falls out of phase-4 scale work |

Memory rule: matrices are built, factored, solved, and discarded **one
mode at a time** (results accumulate in the modal far-field sums), so peak
memory is one mode's system, not the whole mode set.

Key saver: for an **aspect sweep at fixed frequency, the per-mode matrices
factor once** — additional angles are RHS solves only. (Note the mode
*count* is set by the largest aspect in the sweep.)

## 5. Risks & mitigations

1. **Modal kernel singular quadrature** — highest technical risk.
   Mitigate: brute-force adaptive-integration reference harness from day
   one; log-extraction pattern proven in 2D.
2. **Axis endpoint conditions** — classic source of silent nose-on errors.
   Mitigate: sphere gate is run at *all* aspects; cone-sphere nose-on gate.
3. **PMCHWT conditioning at high contrast / junctions** (partial coatings
   meeting PEC on the generatrix). Mitigate: phase-3 junction tests;
   Müller as fallback formulation.
4. **Scale creep** (X-band full-size targets). Mitigate: cost model above
   sets expectations; native assembly kernel is a bounded, late
   optimization with the ctypes pattern already proven in this repo.

## 6. Explicit non-goals (this scope)

- Non-axisymmetric features (fins, lugs): BoR cannot represent them.
  Standard practice is BoR body + component estimates for fins; a true 3-D
  MoM is out of scope.
- Non-air background, layered half-space/ground effects.
- 2.5-D oblique-incidence extension of the 2D solver (different tool,
  doesn't reach nose-on; superseded by BoR).
